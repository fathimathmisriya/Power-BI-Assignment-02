# Power BI Assignment 02

## Overview
This assignment focuses on data visualization and basic calculations using Microsoft Power BI. It helped me understand how to present data clearly and analyse information using charts and DAX formulas.

## Tasks Completed
- Created a clustered column chart to compare orders by country.
- Created a line chart to analyse orders by date.
- Created a pie chart to show layoffs by location.
- Created a calculated column to find the total price.
- Used DAX measures to calculate total quantity, row count, valid records, missing values, minimum price, and maximum price.

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)

## Learning Outcome
This assignment improved my understanding of data visualization, calculated columns, and DAX measures. It also helped me learn how to summarize data and present findings in a clear and meaningful way.
